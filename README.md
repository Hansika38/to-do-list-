# Smart To-Do List App 📝

A lightweight, responsive, and interactive To-Do List application built using native frontend web technologies. This project features dynamic DOM manipulation, persistent state storage, custom priority grouping, live status analytics, and a theme configuration engine.

## 🚀 Live Demo
https://hansika38.github.io/to-do-list-/

---

## ✨ Features

- **Persistent Storage:** Tasks and theme configurations stay saved even after closing or refreshing the browser using `localStorage`.
- **Priority Grouping:** Color-coded priority tags (High 🔴, Medium 🟡, Low 🟢) to quickly categorize tasks.
- **Dynamic Task Filtering:** Instantly isolate tasks into **All**, **Pending**, or **Completed** categories.
- **Live Task Counter:** Real-time updates showing exactly how many pending actions are left on your dashboard.
- **Batch Operations:** A "Clear Completed" utility to wipe out done tasks with a single click.
- **Persistent Dark Mode:** Modern theme configuration that syncs seamlessly with browser memory.
- **Accessible UX:** Full support for keyboard workflows (press `Enter` to submit tasks) and clean animations.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layout controls.
- **CSS3:** Custom linear gradients, responsive flexbox positioning, active button states, and CSS keyframe animations.
- **JavaScript (ES6):** Native DOM Event listeners, dynamic component construction, and browser API integration.
